# 끝말잇기 봇

방언, 북한어, 옛말까지 아는 봇과 두는 끝말잇기입니다.

**https://ansoeuanq.github.io/kkeutmal/** 에서 바로 할 수 있습니다.

## 앱으로 설치하기

- 안드로이드·PC (크롬, 엣지): 화면의 "앱으로 설치" 버튼을 누르거나, 주소창의 설치 아이콘을 누릅니다.
- 아이폰·아이패드: 사파리의 공유 버튼을 누른 뒤 "홈 화면에 추가"를 고릅니다.
- 안드로이드 앱 파일: [kkeutmal.apk](https://github.com/ansoeuanq/kkeutmal/releases/latest/download/kkeutmal.apk)를 받아 설치합니다.
  스토어 밖에서 받은 앱이라 설치할 때 "출처를 알 수 없는 앱" 허용을 묻습니다. 앱은 위 주소의 게임을 그대로 엽니다.

한 번 열어 본 뒤에는 인터넷이 없어도 열립니다. 단어 뜻은 전에 본 단어 묶음만 오프라인에서 보입니다.

## 룰

| 룰 | 쓸 수 있는 말 |
|---|---|
| 구엜룰 | 표준국어대사전(2019년 6월 25일 판)의 명사 |
| 신엜룰 | 표준국어대사전(현행판)의 명사 |
| 넶룰 | 표준국어대사전과 우리말샘을 합친 명사 |
| 우샘룰 | 우리말샘의 명사 |
| 쿵쿵따 | 우리말샘의 3글자 말 (품사는 가리지 않음) |

- 화면 맨 위에 지금 룰에서 쓸 수 있는 말이 "명사 사용 가능"처럼 나옵니다.
- 처음 3번(나와 봇 각자, 처음 6단어)은 한방단어를 쓸 수 없습니다.
- 처음 들어오면 늘 내가 먼저 시작합니다.

## 업데이트 내역

### 2026-10-15 (세 번째)

- 봇이 자가 대국과 스파링(표준어만 아는 상대와의 대국)으로 100만 판씩 더 배웠습니다.
- **봇 하나로 합쳤습니다.** "자가 대국으로 배운 봇 / 스파링으로 배운 봇"을 고르던 칸이 없어지고, 두 가지로 배운 것을
  합친 봇 하나와 둡니다.
- 업데이트할 때 **두던 판은 끝까지 둘 수 있습니다.** 판이 끝난 뒤에 "업데이트 중"이나 "새 버전" 창이 뜹니다.

### 2026-10-15 (두 번째)

- 구엜룰·신엜룰·넶룰·우샘룰을 **다시 명사만 쓰는 예전 규칙**으로 되돌렸습니다. 형용사·부사는 쓸 수 없습니다.
- 네 룰의 봇은 되돌린 사전으로 100만 판씩 다시 배웠습니다.

### 2026-10-15

- 구엜룰·신엜룰·넶룰·우샘룰에서 **형용사와 부사**도 쓸 수 있습니다(예: 예쁘다, 빨리). 형용사는 기본형(…다)으로 냅니다.
- 한방단어 금지가 처음 5번에서 **처음 3번**으로 줄었습니다.
- **자유 룰을 없앴습니다.** 나머지 다섯 룰만 남습니다.
- 화면 맨 위에 그 룰에서 쓸 수 있는 말을 보여 줍니다.
- 처음 들어오면 늘 내가 먼저 시작합니다.
- 봇은 바뀐 사전과 규칙으로 룰마다 100만 판씩 처음부터 다시 배웠습니다.
- 승률 기록을 처음부터 다시 모읍니다.
- **업데이트하는 동안에는 앱과 웹이 잠깁니다.** "업데이트 중이에요" 창이 뜨면 잠시 뒤에 다시 확인을 누르세요.
  옛 버전으로 열려 있으면 "새 버전이 나왔어요" 창이 뜨고, 새로 고치면 새 버전이 열립니다.

## 이 저장소

게임을 실행하는 파일만 자동으로 올리는 배포용 저장소입니다. 여기서 직접 고치지 않습니다.

## 자료 출처와 라이선스

- 단어 자료: 국립국어원 [우리말샘](https://opendict.korean.go.kr/)과 [표준국어대사전](https://stdict.korean.go.kr/),
  [spellcheck-ko/korean-dict-nikl](https://github.com/spellcheck-ko/korean-dict-nikl) 저장소의 덤프를 가공했습니다.
- `data/words.txt`와 `data/defs/`는 그 자료에서 표제어·구분·품사·뜻풀이를 뽑은 2차 저작물이며
  [CC BY-SA 2.0 KR](https://creativecommons.org/licenses/by-sa/2.0/kr/)을 따릅니다.
