# 끝말잇기 봇

방언, 북한어, 옛말까지 아는 봇과 두는 끝말잇기입니다.

**https://ansoeuanq.github.io/kkeutmal/** 에서 바로 할 수 있습니다.

## 앱으로 설치하기

- 안드로이드·PC (크롬, 엣지): 화면의 "앱으로 설치" 버튼을 누르거나, 주소창의 설치 아이콘을 누릅니다.
- 아이폰·아이패드: 사파리의 공유 버튼을 누른 뒤 "홈 화면에 추가"를 고릅니다.
- 안드로이드 앱 파일: [kkeutmal.apk](https://github.com/ansoeuanq/kkeutmal/releases/latest/download/kkeutmal.apk)를 받아 설치합니다.
  스토어 밖에서 받은 앱이라 설치할 때 "출처를 알 수 없는 앱" 허용을 묻습니다. 앱은 위 주소의 게임을 그대로 엽니다.

한 번 열어 본 뒤에는 인터넷이 없어도 열립니다. 단어 뜻은 전에 본 단어 묶음만 오프라인에서 보입니다.

## 이 저장소

게임을 실행하는 파일만 자동으로 올리는 배포용 저장소입니다. 여기서 직접 고치지 않습니다.

## 자료 출처와 라이선스

- 단어 자료: 국립국어원 [우리말샘](https://opendict.korean.go.kr/)과 [표준국어대사전](https://stdict.korean.go.kr/),
  [spellcheck-ko/korean-dict-nikl](https://github.com/spellcheck-ko/korean-dict-nikl) 저장소의 덤프를 가공했습니다.
- `data/words.txt`와 `data/defs/`는 그 자료에서 표제어·구분·품사·뜻풀이를 뽑은 2차 저작물이며
  [CC BY-SA 2.0 KR](https://creativecommons.org/licenses/by-sa/2.0/kr/)을 따릅니다.
